
# 🍜 Nintai Ramen — Landing Page Web

**Nintai Ramen** es una landing page moderna, responsive y visualmente atractiva diseñada para un restaurante de ramen artesanal inspirado en la gastronomía japonesa. El sitio busca transmitir una experiencia auténtica y sofisticada, destacando la historia de la marca, un menú variado y un sistema intuitivo para la reserva de mesas.

---

### 🚀 Tecnologías y Herramientas Utilizadas

* **HTML5 Semántico:** Estructuración limpia del documento utilizando elementos semánticos (`<nav>`, `<section>`, `<footer>`, `<form>`) para garantizar accesibilidad y optimización SEO.
* **CSS3:** 
  * **Flexbox y CSS Grid:** Layout totalmente adaptativo para las tarjetas de platos, la sección *"Sobre Nosotros"* y bloques informativos.
  * **Media Queries:** Diseñado bajo enfoque responsive para desktop, tablets y dispositivos móviles.
  * **Transiciones y Pseudo-clases:** Microinteracciones visuales al pasar el cursor (`:hover`) y estilos personalizados para campos de formulario.
* **JavaScript (ES6+):**
  * **API `IntersectionObserver`:** Animaciones de revelado fluido (*Scroll Reveal*) a medida que el usuario navega por la página.
  * **Manipulación del DOM:** Filtrado dinámico por categorías en la sección de menú (*Ramen*, *Entradas*, *Bebidas*) sin recargar la página.
  * **Navegación Móvil:** Menú hamburguesa desplegable interactivo.

---

### ✨ Características Principales

1. **Hero Section:** Portada de alto impacto con llamada a la acción para reservas.
2. **Menú Interactivo:** Navegación por pestañas con filtrado en tiempo real.
3. **Sección Informativa:** Presentación de la marca y métricas clave (horas de cocción, valoraciones).
4. **Formulario de Reservas:** Captura estructurada de datos (nombre, teléfono, fecha, hora y comensales).
5. **Diseño Responsive:** Adaptado para una experiencia óptima en cualquier dispositivo.
